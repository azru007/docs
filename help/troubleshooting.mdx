If something isn't working as expected in Wild Guess & Match, this guide covers the most common issues and how to fix them.

## Sound and Music Issues

<AccordionGroup>
  <Accordion title="No sound at all">
    Make sure the blue **Sound button** in the top bar shows the speaker-on icon. If it shows a muted icon, tap it to unmute. Also check your device volume and ensure the browser tab is not silenced.
  </Accordion>

  <Accordion title="Animal names aren't being spoken">
    Text-to-speech uses your device's built-in voice engine. Some browsers or devices may not support it. Try **Chrome** or **Edge** on desktop for the best experience.
  </Accordion>

  <Accordion title="Background music stopped">
    The purple **Music button** in the top bar controls music. Tap it to turn music back on. Note that some mobile browsers require a tap on the page before audio can start.
  </Accordion>
</AccordionGroup>

## Profile and Coins Issues

<AccordionGroup>
  <Accordion title="Profile missing after browser update">
    Your profile data is stored in the browser. If the browser cleared its data, the profile is gone. Ask a parent to create a new profile.
  </Accordion>

  <Accordion title="Coin balance looks wrong">
    Coins sync to the cloud after each game action. If you notice a discrepancy, wait a few seconds and the balance will update to the server-verified amount.
  </Accordion>

  <Accordion title="Cannot unlock Drawing Studio even with 50+ coins">
    Make sure the coin count shown in the top bar is **50 or more**. If the **Unlock** button is still greyed out, try refreshing the page.
  </Accordion>
</AccordionGroup>

## Leaderboard Issues

<AccordionGroup>
  <Accordion title="Leaderboard shows 'Could not connect'">
    This means the game could not reach the score server. Check your internet connection and tap **Try Again**. If the issue persists, try again later.
  </Accordion>

  <Accordion title="My score is not on the leaderboard">
    Scores are submitted automatically after each correct answer. If you were offline, scores may not have been recorded. A stable internet connection is needed for leaderboard tracking.
  </Accordion>
</AccordionGroup>

## Drawing Studio Issues

<AccordionGroup>
  <Accordion title="Canvas is blank after refreshing">
    The canvas drawing is not saved to the server — only finished **Save Poster** images are stored. Any in-progress drawing is lost on refresh. Use **Save Poster** often!
  </Accordion>

  <Accordion title="Stamps aren't appearing on the canvas">
    Make sure the **Stamp** tool is selected (not Brush or Eraser) and that you have tapped on the canvas area. Adjust the **Size** slider to make stamps larger if they're hard to see.
  </Accordion>
</AccordionGroup>

## Browser Compatibility

Wild Guess & Match works best in modern browsers. Recommended:

- **Chrome** 90+
- **Firefox** 88+
- **Safari** 14+ (iOS and macOS)
- **Edge** 90+

<Warning>
  Internet Explorer is not supported.
</Warning>
